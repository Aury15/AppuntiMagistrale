A block cipher like AES can cipher only a block of fixed-size at a time. The **block cipher modes of operations** defines how applies repeatedly AES for cipher longer than a block, continuous streams of data, entire hard drives, or database fields without introducing vulnerabilities.  

#### The repetitions problem and the initialization vector
If you encrypt two identical blocks of plaintext ($P_1 = P_2$) using the same key $K$, AES will always produce two identical ciphertext blocks ($C_1 = C_2$), revealing the message structure to an outside observer. To avoid this problem, almost all modes of operation introduce an **Initialization Vector** (IV). The initialization vector is a block of casual data bigger like a cipher's block, for AES 16byte. It is used for starting the process of encryption and to introduce randomness from the very first block.
